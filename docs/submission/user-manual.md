# 用户手册

本手册对应 DGFlow Lab 研究原型。启动方法见[部署说明](deployment.md)，设计与实测结论见[设计报告](design-report.md)。本文中的建议参数是操作配置，不是已经取得的实验结果。

## 1. 打开并检查实验台

在运行控制服务的机器上打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。顶部深色导航栏左侧为产品标识，中间是“首页 / 看板 / 部署 / 监控 / 验证 / 对照”六个页面入口，右侧显示与实验引擎的连接状态和在线节点数；后端版本号显示在除满屏监控外的页面页脚。

创建任务前检查“实验数据”是否就绪，在“部署”页检查当前节点健康状态。新默认部署包含 6 个客户端、3 个边缘授权节点、4 个云聚合节点。旧部署保留实际节点数，普通重启不会自动扩容。“监控”页的资源曲线来自实验保存的遥测，不通过界面动画推测在线状态。

“准备实验数据”会按部署页所选数据集下载或校验本地 MNIST 或 CIFAR-10 缓存；两者分别检查就绪状态，有完整缓存时复用并核验。离线前应提前准备依赖和所选数据集，每台客户端主机及控制主机都需要相应缓存。任务运行时不能重新准备数据；若页面连接中断，页面保留上次读到的结果并明确标记失联。

## 2. 配置实验

“部署”页左侧是编号步骤卡片，依次设置策略、训练条件与异常场景；右侧是节点拓扑画布，底部操作栏提供“高级模式”“重置”、预设与“运行 DGFlow”。随机种子控制数据划分与训练随机性，不用于密码随机数。

拓扑可配置客户端 n（2–100）、边缘 w（2–32）、云 v（2–32），以及边缘门限 s（2–w）和云门限 e（2–v）。在空闲时应用到本机部署，再创建新任务；活动任务的拓扑固定，运行中不能修改。每个客户端只连接一个归属边缘，默认按编号轮流分配。所有边缘共同建钥并共享函数钥份额，归属边缘核验其客户端的证明与评分，再共享签名结果和密文核心供共同筛选、授权及云聚合；VerDec 在归属边缘内部执行。新任务绑定实际归属映射，不能让退役角色或跨归属提交参加。

| 参数 | 范围及含义 |
| --- | --- |
| 实验策略 | `plain`、`encrypted`、`dgflow`、`optimized`。各模式区别见下表。 |
| 密码证明 | 新加密实验固定使用 LegoGroth16（`lego_norm_v1`），需预先安装并选择匹配 CRS；明文基线无需证明和 CRS。 |
| 数据集 | MNIST（灰度）或 CIFAR-10（RGB），分别准备缓存。当前安全流程均使用池化线性分类器，论文 CNN 尚未接入。 |
| 模型规模 | MNIST 的 `grid` 为 2–28，维度为 `grid²×10+10`，默认 650、最高 7,850 坐标；CIFAR-10 的 `grid` 为 2–25，维度为 `3×grid²×10+10`，默认 1,930、最高 18,760 坐标。所有模式最多 20,000 坐标。维度增加会增加计算与通信工作，实际时延受并行、缓存和其他开销影响，应以实测为准。 |
| 全局训练轮数 | 1–20。先用 1 轮验证端到端路径，再按实际资源扩大。 |
| 本地训练轮数 | 1–5。每个客户端每轮的本地训练次数。 |
| 随机种子 | 0–2,147,483,647 的整数。比较策略时保留相同种子。 |
| 训练样本上限 | MNIST 为 120–60,000，CIFAR-10 为 120–50,000。是公开训练集子集上限，不是每个客户端各自的条数。 |
| 测试样本上限 | 100–10,000。来自单独的公开测试集。 |
| Non-IID | 启用人为构造的异质分区；关闭时采用 IID 划分。不代表真实机构数据划分。 |
| 异常客户端 | 0–n。无攻击时固定为 0；指定异常场景时至少为 1，不能超过本任务客户端数。 |
| 本轮排除聚合节点 | 0–v。剩余云数量必须至少达到云门限 e，否则不能启动；逻辑上不调用被排除的云，进程可能仍在线。 |

| 策略 | 查看结果时的解释 |
| --- | --- |
| 明文基线 | 聚合流程可见本地模型，不生成密码证明，无需 CRS；按所选分组策略接纳成员。 |
| 加密聚合 | 执行加密与 LegoGroth16 证明校验，但不执行相似度异常筛选。 |
| DGFlow | 执行 LegoGroth16 密文验证、相似度筛选和所选分组策略下的成员接纳。 |
| 改进策略 | 保留与 DGFlow 相同的验证与筛选条件，兼容历史实验模式名；执行参数可独立设置。 |

自动执行对所有模式使用有界并行。需要比较串行与并行速度时，请显式选择“串行对照”与“并行”，并保持数据、模型、证明、门限和轮数相同；不能仅比较 DGFlow 与改进策略两个模式名。

新加密实验统一使用 LegoGroth16，需要选择与当前模型维度及 8 位量化匹配的 CRS。完整部署会在目标运行目录核验或补齐 MNIST 650 维和 CIFAR-10 1,930 维的默认开发参数：已有完整参数复用并保留指纹，缺少时本地生成，离线也不下载参数。纯源码不携带运行目录、生成的 CRS 或身份；角色及实验启动本身不生成 CRS。

依赖已就绪的旧运行目录可执行 `python scripts/setup_lego_parameters.py --runtime runtime --defaults` 补齐两组默认参数，其中 `python` 须使用项目环境的解释器。完成后在页面点击“刷新已安装参数”，再手动选择匹配指纹，无需重启服务。650 维参数不能用于 1,930 维模型；改变池化网格后的非默认维度仍需显式 `--dimension`。这些是单方开发参数，不代表正式多方可信设置仪式；三机必须共享同组公共 PK/VK、清单和指纹，不要各自随机生成。命令和完整离线包复用方法见 [README](../../README.md)。切换到明文基线时无需选择 CRS。

旧逐坐标证明及 5A/5B 已退出新建实验选项。历史任务保留原证明方案、配置和性能数据；查看历史记录不代表可以用原配置创建新任务，比较耗时前还需核对证明方案和 CRS。

本机同时运行多个角色时，启动器默认将 OpenBLAS、MKL、BLIS、OpenMP、NumExpr 和 Rayon 的常驻线程预算设为 1，避免每个进程按整机核心数重复建池。标准环境变量的显式设置原样保留；密码验证的“线程数”和证明工作进程仍按实验配置执行。调整这些环境变量后，需要在空闲时重启角色；直接手动运行单个 `node` 命令时应自行设置合适预算。

高级设置中的“云聚合方式”默认自动，也可明确选门限云或全部可用云。自动依据实际可用云数量：没有多余云时用全部云，GPU 有多余云时用门限云，CPU 只有在可用云数至少为 2e 时用门限云；这是可覆盖的调度规则，不能保证所有机器最优。配置和结果分别记录请求方式与实际选择。门限方式按编号先请求 e 个云，只有连接缺席或超时才调用候补；证书、签名、响应或数学证明错误会终止任务。主控先完整验证选定的同一组结果，随后全部边缘独立核验，达到一致结果后才发布模型。“全部可用云”保留为对照路径。较旧服务未声明支持时，页面继续提交原来的全部云请求格式。

各参数的独立范围不代表其所有组合都能运行。系统在提交前检查密码消息的编码下界，若已确定超过单次 1 GiB 上限，会指出应减少的数量、门限或模型网格；通过这项检查也不代表 RAM、显存或实际含签名消息一定足够。

异常类型包括标签翻转、完整模型向量符号翻转、随机模型向量、证明篡改和客户端退出。它们是受控实验中的预设攻击，不是自适应攻击或复杂后门防御的完整验证。明文模式没有密码证明，所以在明文模式下选择证明篡改并不能构成证明系统测试。

点击“运行 DGFlow”后，页面跳转至运行监控。系统同时只允许一个活动任务；重复点击不会有意创建第二个任务。按钮因节点未初始化、数据未就绪、任务正在执行或参数无效而禁用时，右侧“启动前检查”卡片会说明原因。

## 3. 查看运行监控

全站导航下方满屏自动加载原生 TensorBoard，默认显示所选实验的全局测试、客户端本地训练和资源曲线，初始平滑为 0。原生“实验记录”列表中的日志路径区分节点与主机；清空“筛选实验（正则表达式）”后勾选多个实验即可比较。资源约每 5 秒采集、当前日志约每 10 秒同步、原生自动刷新默认每 30 秒；后台同步保留筛选、平滑与缩放操作。监控页不再显示外层摘要、节点表、协议详情或页脚。指标定义、历史补录与三机部署的采样范围见[监控与 TensorBoard](monitoring.md)。

在“看板”的“当前实验”选择已有记录后进入监控；也可直接用 TensorBoard 的运行列表筛选已导出的日志。运行期间每个轮次只有在后端返回完整结果后才进入曲线；页面不会用假曲线填补等待时间。

- **已完成轮次：** 已保存的完整轮次，而非当前正在计算的轮号。
- **最新准确率与损失：** 当前公开测试集上的实测指标。没有完成轮次时显示横线。
- **客户端训练集指标：** 每个本地 epoch 后评估该客户端实际训练分区，记录量化前、训练后攻击变换前的模型。横轴为累计本地 epoch，与全局测试指标分开；评估耗时另列，不参与筛选或密码验证。
- **总执行耗时与协议通信量：** 看板和导出记录保留后端汇总字段；通信量是应用层请求与响应字节，不包含完整 TLS/HTTP 帧开销。监控通信量在结果中独立统计。
- **节点与主机资源：** 节点 CPU/RSS 包含已核验子进程；主机整机 CPU、内存、磁盘及 GPU 每台机器一份，包含其他应用负载，不把同机 GPU 重复算到多个节点。旧实验未采集的值不会生成资源曲线。
- **阶段墙钟耗时：** 建钥、客户端阶段、验证授权和聚合确认等阶段的实际经过时间；保留在日志与完整导出记录中。阶段小计不自动包含评估和其他开销。
- **验证与聚合子阶段：** 聚合密钥派生、云部分解密、合并核验等用时已包含在所属顶层阶段内，只用于定位瓶颈，不能再次加入阶段总计。合并内部主控计时也不代表全部节点的并行墙钟。
- **各客户端累计调用耗时：** 每个客户端训练、加密、证明生成的用时相加，已包含在客户端阶段内。并行情况下不能把这些累计值再加到墙钟时间上，也不能当作 CPU 利用率。

完整导出记录保留实际阶段事件、后端消息和轮次。“生成证明”不意味着已完成验证；异常结束也不会被当成成功训练。

在“看板”点击“停止任务”只发送停止请求。正在执行的密码调用可能需要安全结束后才响应；应等待后端状态，不要把按钮文字变化当作节点已退出。停止训练任务不会停止节点服务。

## 4. 检查验证与异常

按轮次查看各客户端的证明状态、评分、决定和理由。评分缺失显示横线，明文路径没有证明时显示“不适用/未提供”。

**未接纳客户端数包含批次连带排除。** 两个数字不能简单相加作为总拒绝数。新实验默认“重新组队”：所有合格幸存成员共同组成至少两人的授权组，保留奇数人数，只有一人合格时不发布聚合。高级设置中可选择旧“固定批次”，此时 `client1+client2`、`client3+client4`、`client5+client6` 必须完整，其他成员未通过或缺席会造成连带排除；被连带成员不一定恶意。

鲁棒模式高级设置默认最小余弦为 0、最大 L2 范数为合格候选群体下中位数的 2 倍，可另填平方范数绝对上限；范数使用密码证明已验证的量化整数值。相对门限依赖诚实多数，正常异质分布需要校准；参数在创建任务后固定。明文与仅加密模式保留不筛选的实验基线。

如果验证结果已返回，但聚合因门限不足或其他原因没有发布模型，界面会显示“验证记录已返回，模型尚未发布”。此时接纳代表验证阶段资格，不能视为成功完成了一轮训练。

证明通过只说明被检查的密文、编码范围、实际密钥与平方范数关系一致；异常筛选还依赖有限统计和工程规则。诚实异质数据也可能被排除，恶意更新也可能通过筛选。最终应同时查看准确率、误杀与连带影响，而不是只数拒绝条目。

## 5. 比较与导出

“实验对比”最多选择四个已完成或已中止的任务。页面标记“历史实测”，展示逐轮准确率和汇总值。“最高准确率”取已完成轮次的最大值，“最终准确率”取最后一个已完成轮次；没有完成轮次时显示横线。任务结束后页面重新取得完整结果，不复用运行中或摘要未齐的缓存。失败任务保留在任务选择器中用于排错，但不列入此页比较。

比较前核对数据集、模型维度、种子、训练后端、IID/Non-IID、异常类型、异常客户端数、排除聚合节点数、数据上限与本地轮数。页面阻止跨数据集曲线对照；同一数据集的其他配置不一致时，也不能把曲线差异全部归因于策略。

点击“导出记录”下载真实 JSON。导出保留任务标识和配置用于复验；提交材料时应复查异常文本与路径是否含环境身份信息。不要导出或分发整个 `runtime/keys`。页面截图只能说明当时界面状态，正式指标应引用导出记录或性能报告。

## 6. 常见问题

| 情况 | 处理方法 |
| --- | --- |
| API 未连接 | 确认控制服务仍在运行，使用本机 8765 地址，检查终端错误。页面自动重试。 |
| 数据未就绪 | 在联网准备阶段运行 `prepare-data --dataset mnist` 或 `prepare-data --dataset cifar10`，核验对应主机上的完整缓存；训练阶段不会自动下载。 |
| 没有匹配 CRS | 完整部署应补齐默认 650/1,930 维参数；旧运行目录可执行 `setup_lego_parameters.py --runtime runtime --defaults`。非默认维度须显式 `--dimension`，随后刷新参数列表并选择；明文基线无需 CRS。 |
| 节点为空 | 先初始化并启动节点。数据就绪不代表节点已运行。 |
| 节点离线 | 检查该节点日志、端口、证书与配置地址。不要关闭证书验证以掩盖错误。 |
| 无完整合格批次 | 本轮合法参与集合为空，系统中止而不发布伪结果；查看直接拒绝与连带排除。 |
| 聚合节点不足 e/v | 当前剩余可用云少于所设门限 e，不能恢复聚合模型；检查逻辑排除与实际健康状态。 |
| 任务不存在 | 记录已被移除或运行目录已切换；重新选择当前后端已有任务。 |
| 停止后长时间等待 | 密码调用仍可能进行；先查看日志。不要随意结束与本系统无关的进程。 |
| 页面未更新 | 重新构建 `web/dist` 并刷新。开发时可用 Vite 5173，正式演示使用 8765 的构建页面。 |

## 7. 隐私与可用性边界

当前是公开 MNIST 或 CIFAR-10 的本地重放，不是对真实机构私有数据的实证验证。每个客户端可以拥有相同公开缓存，代码按规则选择本地分区；跨机器复制公开数据不构成真实机构隔离。

授权内积、平方范数、相似度和聚合模型属于允许输出。系统没有提供差分隐私意义的零泄漏承诺。s/w、e/v 门限覆盖密钥恢复与聚合组件条件，新任务 DKG 仍需要全部 w 个边缘，主控仍是 RPC 转发及编排单点；两者与整台主机故障容错不能混用。单归属拓扑对齐不代表完整论文安全证明、性能或 PFLlib CNN 复现；历史记录仍以其原有配置解释。
